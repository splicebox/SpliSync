# SpliSync ablation training

These scripts reproduce the manuscript ablations used to assess the
contributions of genomic pretraining, sequence information, and alignment
information. All variants use the same 512-channel-input 1D U-Net architecture
and task-training procedure.

## Models

| Entry point | Model |
| --- | --- |
| `train_random_hyena.py` | Frozen randomly initialized eight-layer HyenaDNA plus pile-up |
| `train_alignment_only.py` | Zero-filled sequence channels plus pile-up |
| `train_sequence_only.py` | Frozen pretrained eight-layer HyenaDNA plus zero-filled alignment channels |
| `train_onehot_cnn.py` | One-hot three-layer CNN plus pile-up |

## Input layout

`--data_dir` must point to a dataset generated by
`curate_dataset.train.py` and contain:

```text
DATA_DIR/
└── training/
    ├── train
    ├── train.pileup_embed/
    ├── val
    └── val.pileup_embed/
```

## Usage

Run from the SpliSync repository root:

```bash
python supp_scripts/ablation/train_random_hyena.py \
  --data_dir /path/to/DATA_DIR

python supp_scripts/ablation/train_alignment_only.py \
  --data_dir /path/to/DATA_DIR

python supp_scripts/ablation/train_sequence_only.py \
  --data_dir /path/to/DATA_DIR

python supp_scripts/ablation/train_onehot_cnn.py \
  --data_dir /path/to/DATA_DIR
```

Checkpoints are written to:

```text
OUTPUT_ROOT/<ablation>/
```

## Inference

The random-initialized HyenaDNA model has the same architecture as the full
SpliSync model and can be used directly with the repository's
`run_inference.sh` by setting `MODEL_CKPT` to the random-Hyena checkpoint.

For the alignment-only, sequence-only, and one-hot CNN architectures, run
inference on an already curated feature directory with:

```bash
python supp_scripts/ablation/infer_component_ablation.py \
  --data_dir /path/to/inferencedata_INPUT_BAM.merge \
  --model_path /path/to/ablation.ckpt \
  --output /path/to/predictions.tsv
```

The architecture is inferred from checkpoint metadata. It can also be
specified explicitly:

```text
--ablation alignment_only
--ablation sequence_only
--ablation onehot_cnn
```

## Common prediction post-processing

The full model and all ablation models use the same prediction
post-processing. Calls with both alignment features equal to zero at the
predicted coordinate are removed, as are calls without aligned-read coverage
within the 16-bp vicinity. No nearby-call merging or additional local
spliced-read-support filter is applied.
